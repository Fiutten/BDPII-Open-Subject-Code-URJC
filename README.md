# Código docente de Big Data Processing II

Repositorio público de la categoría 6 (programas de ordenador) de la asignatura **Big Data Processing II**, del **Máster Universitario en Análisis de Datos Deportivos** de la Universidad Rey Juan Carlos.

## Autoría

- Alberto Fernández Isabel (profesor responsable)
- Natalia Madrueño Sierro
- Rubén Rodríguez Fernández

Curso académico: 2026-2027.

## Contenido

El directorio `codigo/` contiene ejemplos, notebooks y recursos docentes organizados por temas:

- **Tema 1 — Procesamiento Big Data distribuido:** notebooks `streaming.ipynb` y `streaming_soluciones.ipynb`.
- **Tema 2 — Streaming en tiempo real:** productor Kafka, datos sintéticos de sensores deportivos y entorno Spark con el notebook `spark_streaming.ipynb`.
- **Tema 4 — IA generativa:** ejemplos de RAG, flujos y agentes, con sus dependencias.
- **Tema 5 — Proyecto integrado:** ejercicio Text-to-SQL con Spark y LangGraph.

Se publican **tres notebooks** en total. Los archivos con credenciales reales no forman parte del repositorio; los ejemplos que requieren servicios externos usan variables de entorno y, cuando procede, un fichero `.env.example`.

## Ejecución

Cada bloque conserva sus instrucciones y dependencias. Consulte los README y ficheros `requirements.txt`, `pyproject.toml` o `docker-compose.yml` dentro de cada tema.
